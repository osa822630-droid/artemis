# ARTEMIS في Claude Web عبر Add marketplace

الإضافة هنا مهيّأة بصيغة Claude plugin marketplace: ملف الفهرس في
[`.claude-plugin/marketplace.json`](../.claude-plugin/marketplace.json)، والإضافة
المستقلة في [`plugins/artemis`](../plugins/artemis).
لا تحتاج أوامر Claude Code لإضافتها من واجهة الويب التي تعرض **Add marketplace**.

## الإضافة من الويب

1. افتح قسم الإضافات/الـ marketplace في Claude Web، ثم **Add marketplace**.
   قد تختلف أسماء ومكان القوائم حسب إصدار الواجهة.
2. أدخل رابط الفورك:

   ```text
   https://github.com/osa822630-droid/artemis
   ```

   إذا كان الحقل يطلب `owner/repo` بدل الرابط الكامل، استخدم:

   ```text
   osa822630-droid/artemis
   ```

3. افتح **artemis-marketplace** وثبّت إضافة **artemis** وفعّلها للمحادثة حسب الواجهة.
4. جرّب طلبًا عاديًا، بدون أوامر terminal:

   > استخدم ARTEMIS لكتابة خطة اختبار لتسجيل الدخول في تطبيق أندرويد.
   > وضّح الحالات المتوقعة، واعتبر أي اختبار لم يتم تنفيذه «لم يُنفّذ».

لا نفرض اشتراكًا مدفوعًا في ملفات الإضافة. إذا كانت واجهة حسابك المجاني تعرض
**Add marketplace** فهذه هي طريقة الإضافة المقصودة. إتاحة الواجهة وصلاحيات
المهارات والـ connectors يحددها Claude؛ ملفات الريبو لا تغيّر قيود الحساب.

## ما الذي تضيفه؟

مهارة **artemis-mobile-testing** لإعداد خطط اختبارات Android، تحليل صور الشاشة
والسجلات المرفوعة، وصياغة اختبارات قابلة لإعادة الإنتاج. تعمل تعليماتها بدون
MCP، لكن لا تدّعي أنها نفّذت اختبارًا أو اتصلت بموبايل بدون أدوات فعلية.

عند وجود أدوات ARTEMIS المتصلة، تستخدم المهارة تشخيص البيئة، ملاحظة الشاشة،
تشغيل المهام، متابعة حالتها، وفحص آثار التنفيذ.

## مهم: تثبيت الإضافة ليس توصيل الموبايل

المشروع الأصلي يشغّل ARTEMIS بجانب جهاز Android أو محاكي مع ADB وPython وإعدادات
مزود النموذج. إضافة marketplace تثبّت تعليمات المهارة؛ **لا تثبّت هذه البيئة،
ولا تشغّل Python على كمبيوترك، ولا توفر سيرفرًا مستضافًا**.

للتحكم الفعلي من Claude Web تحتاج أيضًا إلى اتصال MCP منفصل متاح في حسابك،
مرتبط بمضيف ARTEMIS الذي يستطيع الوصول للموبايل. اتصال الويب يحتاج endpoint
بعيدًا متوافقًا مع Claude ومؤمّنًا بالمصادقة وHTTPS. `localhost` أو إعداد
`command`/`args` الخاص بـ stdio ليس رابطًا يصل إليه Claude Web.

هذا التعديل لا يضيف بوابة MCP بعيدة أو مصادقة أو استضافة. لذلك لا يحتوي
الـ plugin على `.mcp.json` يشير لسيرفر وهمي أو محلي. راجع
[دليل السيرفر الحالي](../mcp_server/README.md) لإعداد بيئة المضيف؛ إعداد IDE
المحلي وحده لا يربطها بالويب. لا تنشر ADB أو لوحة الإدارة أو MCP على الإنترنت
بدون حماية. عند عدم وجود اتصال، استخدم رفع الصور والسجلات بعد تنقيح الأسرار.

## حل مشكلات الإضافة

- **Marketplace not found:** تأكد أن المستودع متاح لحساب Claude وأن الفرع الذي
  يقرأه يحتوي `.claude-plugin/marketplace.json` في الجذر.
- **لم تظهر الإضافة:** حدّث/أعد مزامنة الـ marketplace بعد دمج التعديل في الفرع
  الافتراضي، ثم ابحث عن `artemis` داخل `artemis-marketplace`.
- **ظهرت الإضافة لكن لا توجد أدوات:** المهارة والـ MCP شيئان منفصلان؛ تحقق من
  الاتصال وأدوات `mobile_diagnose` و`mobile_run_task`. لا تعِد تثبيت Python
  داخل بيئة دردشة Claude باعتباره بديلًا لمضيف الموبايل.
- **التثبيت نجح لكن المهارة غير مفعّلة:** فعّل الإضافة في المحادثة واطلب
  استخدامها بالاسم. لا تعتبر نجاح التثبيت دليلًا على نجاح اختبار الموبايل.

## للمطورين

المسارات كلها محلية بالنسبة لجذر الإضافة؛ المهارة ومرجعها موجودان داخلها، ولا
يعتمدان على ملفات خارج المجلد قد لا ينقلها عميل الـ marketplace. لا يوجد hook
أو أمر تثبيت تلقائي، ولا مفاتيح أو صلاحيات مفروضة.

لتشغيل فحوص الحزمة بدون تثبيت اعتماديات ARTEMIS أو توصيل جهاز:

```bash
python -m unittest discover -s tests/marketplace -v
```

هذه فحوص بنيوية ومحتوى للحزمة، وليست تجربة تثبيت فعلية في حساب Claude Web.
